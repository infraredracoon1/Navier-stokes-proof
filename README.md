# Navier–Stokes Global Regularity Proof (Anthony Abney)

This repository contains the LaTeX manuscript and reproducible numerical experiments that validate the constants and mechanisms in the proof:

- [A] Spectral gap of angular operator (Monte Carlo).
- [B] Fourier–physical bridge error decay.
- [C] Enstrophy decay via dyadic ODE solver.
- [D] Alignment factor validation via Johns Hopkins Turbulence Database (JHTDB).
